# +ChicasTec | Landing Page del Programa Formativo & Catálogo de 30 Creadoras

Landing Page oficial del **Programa Formativo +ChicasTec (Taller Integrador)**, diseñada con un **tema claro luminoso, limpio y de alto contraste**, articulada con la paleta de colores armónica de **Azul Marino (`#1b365d` / `#0f233d`)** y **Palo Rosa (`#b76e79` / `#c47d89` / `#f9eff1`)**.

## 🌟 Características de la Plataforma

- **30 Tarjetas Dinámicas de las Señoritas**:
  - Cada tarjeta incluye avatar, especialidad, ciudad, frase motivacional, proyecto de página personal, stack de tecnologías y enlaces directos a GitHub y LinkedIn.
- **Buscador en Tiempo Real**:
  - Filtro instantáneo por nombre, ciudad, tecnología (HTML, CSS, JS, Figma, Tailwind, etc.) o proyecto.
- **Filtros por Categoría**:
  - *Todas (30)*, *Frontend Dev*, *UI/UX & Web*, *Full Stack & JS*, *Impacto Social*.
- **Ordenador Inteligente**:
  - *Proyectos Destacados*, *Nombre (A-Z)*, *Nombre (Z-A)*, *Más Valoradas*.
- **Alternador de Vistas**:
  - Vista Cuadrícula interactiva y Vista Lista / Directorio compacto.
- **Sistema de Likes**:
  - Persistencia en `localStorage` con animación y notificaciones Toast elegantes en Palo Rosa.
- **Modal de Detalle / Mockup de Navegador**:
  - Visualizador completo del proyecto personal con soporte para navegación mediante teclado (`←` y `→`, y tecla `Esc` para cerrar).
